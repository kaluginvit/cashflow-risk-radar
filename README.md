# CashFlow Radar

Публичные материалы:

- приложение: https://kaluginvit.github.io/cashflow-risk-radar/
- кейс с двумя кадрами: https://kaluginvit.github.io/cashflow-risk-radar/case.html

- репозиторий: https://github.com/kaluginvit/cashflow-risk-radar

Браузерный инструмент для анализа платёжного календаря, кассовых разрывов и просроченной дебиторской задолженности.

Приложение работает полностью локально: загруженный CSV не передаётся на сервер и не сохраняется во внешних системах.

Портфолио-кейс: [`case.html`](case.html).

## Возможности

- прогноз остатка денежных средств по операциям;
- дата и глубина минимального остатка;
- обнаружение кассового разрыва и его длительности;
- aging просроченной дебиторки;
- концентрация задолженности по контрагентам;
- what-if перенос исходящего платежа;
- экспорт аналитического отчёта в Markdown.

## Быстрый сценарий проверки

1. Откройте приложение.
2. Нажмите «Использовать учебные данные».
3. Исходный прогноз покажет минимум −550 000 ₽ на 13.12.2026.
4. В сценарии оставьте платёж P005 и новую дату 16.12.2026.
5. Нажмите «Пересчитать сценарий».
6. Новый минимум должен составить +50 000 ₽, а кассовый разрыв исчезнуть.

## Локальный запуск

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Тесты

```bash
npm test
```

Тесты проверяют CSV, базовый прогноз, просроченную дебиторку, концентрацию, перенос платежа, итоговый отчёт и ошибочные данные.

## Формат CSV

Обязательные колонки:

```text
id,date,type,category,counterparty,amount,status,due_date,description
```

`type`: `inflow` или `outflow`. Для просроченной дебиторки используются `type=inflow` и `status=overdue`.

## Ограничения

- учебный прототип, а не бухгалтерская система;
- нет интеграции с банком, ERP или 1С;
- даты и суммы не проверяются по первичным документам;
- расчёт не является финансовой, бухгалтерской или инвестиционной рекомендацией.

Для промышленного внедрения потребуются роли, аудит изменений, серверное хранение, импорт из учётной системы и согласование правил с финансовой службой.

## Безопасность данных

Демонстрационный CSV содержит только вымышленные организации и суммы. Не загружайте реальные коммерческие данные в публичные демонстрации.
